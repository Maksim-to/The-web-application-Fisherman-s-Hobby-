## О проекте

Репозиторий содержит исходный код веб-приложения «Рыболов-любитель» — информационной системы для комплексной поддержки любителей рыбалки на территории Российской Федерации. Приложение объединяет справочную информацию о водоёмах, актуальные нормативно-правовые данные, прогноз клёва и инструменты для взаимодействия внутри сообщества.

**Объект исследования:** процессы информационного обеспечения любителей рыбалки.  
**Предмет исследования:** информационная система «Рыболов-любитель» как программный продукт.

**Цель работы:** разработка и создание веб-приложения, обеспечивающего информационную поддержку пользователей в решении задач, связанных с любительской рыбалкой.

---

## Актуальность

Любительская рыбалка — один из массовых видов досуга в России. Однако пользователи сталкиваются с рядом проблем:

- **Фрагментарность информации** о водоёмах, их характеристиках и условиях доступа.
- **Сложность интерпретации нормативно-правовых актов** (Федеральный закон № 166-ФЗ, Правила рыболовства), что повышает риск неумышленного нарушения законодательства.
- **Отсутствие структурированного сообщества** для обмена опытом.

Существующие аналоги — веб-приложение «Где Клюёт!» и мобильное приложение «Прогноз клёва» — не обеспечивают интеграции с нормативно-правовой базой РФ и не предоставляют полноценного структурированного справочника водоёмов. Разработанное приложение закрывает эти пробелы.

## Функциональные возможности

### Справочная база водоёмов
- Структурированный каталог рыболовных мест с фильтрацией по региону, типу водоёма и видовому составу рыбы.
- Детальная информация: описание, инфраструктура, условия доступа.
- Пользовательские отзывы и отчёты.

### Интеграция с нормативно-правовой базой
- Автоматическое отображение запретных периодов (нерест).
- Суточные нормы вылова по видам рыб.
- Перечень разрешённых и запрещённых орудий лова.
- Привязка к региональным правилам (12 рыбохозяйственных бассейнов).

### Прогноз клёва
- Расчёт активности рыбы на основе метеорологических данных (температура, давление, ветер).
- Учёт астрономических факторов (фазы Луны, время суток).
- Температурные оптимумы для каждого вида рыбы.
- Интеграция с нормативными ограничениями (предупреждения о запретах).

### Интерактивная карта
- Визуализация водоёмов на базе API Яндекс.Карт.
- Кластеризация маркеров.
- Фильтрация по региону и виду рыбы.

### Персонализация и личный кабинет
- Регистрация и аутентификация пользователей.
- Ведение дневника рыбалок (дата, место, улов, погодные условия).
- Список избранных водоёмов.
- Персональная статистика (выезды, улов, любимый водоём, частая рыба).

### Социальное взаимодействие
- Публикация отчётов о рыбалке.
- Модерация контента.
- Система комментариев.
- Возможность поделиться ссылкой на отчёт.

### Административная панель
- Управление пользователями (роли: пользователь, модератор, администратор).
- Управление справочниками (водоёмы, виды рыб, снасти, наживки).
- Управление правилами рыболовства.
- Модерация отчётов.

### Справочные разделы
- Каталог видов рыб с описанием, сезонностью и температурными оптимумами.
- Справочник снастей и наживок с рекомендациями по применению.

## Архитектура

Приложение построено на **трёхзвенной клиент-серверной архитектуре**:

- **Уровень представления (frontend)** — HTML5, CSS3, JavaScript, адаптивный интерфейс.
- **Уровень приложения (backend)** — Flask, бизнес-логика, RESTful API.
- **Уровень данных (database)** — SQLite, ORM SQLAlchemy.

Такое разделение обеспечивает модульность, масштабируемость и простоту сопровождения.

## Структура базы данных

База данных включает 23 таблицы, сгруппированные в четыре подсистемы:

### Пользовательская подсистема
- **Пользователь** — учётные данные, роль (пользователь/модератор/администратор), контактная информация.
- **Избранное** — связь пользователей с водоёмами.
- **Отчёт о рыбалке** — записи о выездах с погодными условиями и оценкой.
- **Улов по виду** — детализация улова (вид, вес, количество, снасть, наживка).

### Геоинформационная и нормативно-правовая подсистема
- **Регион** — 22 субъекта РФ с привязкой к рыбохозяйственным бассейнам.
- **Водоём** — 36 водоёмов с координатами и характеристиками.
- **Правила рыболовства** — запретные периоды, лимиты, разрешённые/запрещённые снасти.
- **Лимиты по видам** — суточные нормы и минимальные размеры.
- **Запрещённая снасть** — перечень запрещённых орудий лова по регионам.

### Ихтиологическая подсистема
- **Вид рыбы** — 25 видов с латинскими названиями, температурными оптимумами и сезонностью.
- **Среда обитания** — связь видов с водоёмами.

### Подсистема снаряжения
- **Снасть** — 12 типов снастей.
- **Наживка** — 12 типов наживок.
- **Тип снасти** — категории.
- **Снасть рыбы** / **Наживка рыбы** — рекомендации по применению.

## Безопасность

Реализованные меры защиты соответствуют требованиям **Федерального закона № 152-ФЗ** и **ГОСТ Р 56939-2024**:

- Валидация и санитизация пользовательского ввода (защита от SQL-инъекций и XSS).
- Хэширование паролей алгоритмом PBKDF2-SHA256 с солью.
- Использование HTTPS для шифрования передаваемых данных.
- Разграничение прав доступа на основе ролей.
- Защита от CSRF-атак.
- Ограничение попыток входа.
- Ведение журналов событий безопасности.
